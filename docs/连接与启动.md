# 启动与连接

## 1. 准备

- Windows 11，Python 3.12（安装时启用 `py` 启动器），PowerShell。
- 下载本仓库 ZIP 并解压到自己有写入权限的位置，或用 Git 克隆。路径可自选，不要照抄别人的绝对路径。
- 打算连接 ChatGPT 时，准备可使用自定义 MCP 插件的 ChatGPT 账户，以及可创建 Secure MCP Tunnel 的 OpenAI Platform 组织权限。具体可用权限由账户和工作区决定。

在项目根目录打开 PowerShell：

```powershell
py -3.12 -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
powershell -NoProfile -ExecutionPolicy Bypass -File .\configure_local_plugin.ps1
```

这里会在本机生成 `plugins/shuangli-desktop/.mcp.json`，其中包含下载者自己的项目路径；该文件不上传 GitHub。

## 2. 构建并启动

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
& .\dist\ShuangliCompanion\ShuangliCompanion.exe
```

之后也可双击根目录 `start.cmd`。程序旁的 `data` 保存设置、位置和连接状态。不要把该目录复制回公开仓库。首次只想从源码启动时，运行 `& .\.venv\Scripts\python.exe .\run.py`。

触碰角色或脚下区域显示输入条，Enter 发送；右键可打开设置，拖动可移动或抛掷，Ctrl 加滚轮缩放。Ctrl+Alt+Shift+D 恢复角色；Ctrl+Alt+Shift+C 打开输入条。托盘菜单可解除鼠标穿透。

## 3. 接入自己的 ChatGPT 聊天

按 [桌面聊天插件](桌面聊天插件.md) 下载官方隧道客户端、创建自己的隧道，并在 ChatGPT 中登记 MCP 插件。连接步骤需要下载者在自己的账户页面完成；本仓库不提供共享凭据。

在 ChatGPT 里选中插件并调用 `open_shuangli` 后，保持该 Chat 打开。桌宠输入条的状态指示连接情况。插件未激活时，“复制并打开”会保留草稿并打开 ChatGPT。

## 4. 可选的 Codex 本机插件

`configure_local_plugin.ps1` 写入本机 MCP 配置。Codex 使用时，可通过项目中的 `.agents/plugins/marketplace.json` 安装 `shuangli-desktop` 插件。这个本机入口与 ChatGPT 的 Tunnel 插件登记是两条独立配置，不能互相代替。

## 常见连接检查

- 桌宠未出现：从托盘恢复，或按 Ctrl+Alt+Shift+D；查看程序旁 `data/shuangli.log`。
- ChatGPT 插件找不到隧道：确认隧道关联当前 ChatGPT 工作区，账户具有 Tunnels Read + Use，隧道客户端仍在运行。
- 隧道连接失败：在本机运行官方客户端的 `doctor --profile shuangli-chat --profile-dir data/tunnel-profiles --explain`，并确认 `data` 中的配置属于当前电脑。
- 输入条显示未连接：在目标 Chat 中打开 `open_shuangli` 面板，并保持面板所在聊天可用。

## 浏览器入口

在设置中选择“浏览器原会话”并填写原会话链接，只会打开页面；草稿在页面中手动发送。旧配置中的 `bridge_enabled`、`extension_id` 不再参与运行。

更新已有便携目录时，构建脚本会清理 `extension` 和 `ShuangliBridgeHost.exe`。曾登记浏览器桥接的用户，可在该程序的设置中点击“清理旧浏览器桥接登记”，并在浏览器扩展管理页移除“霜璃 · 原会话桥接”。
