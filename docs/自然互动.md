# 自然互动

`src/shuangli/behavior.py` 调度自然动作，`animation.py` 管理基础状态与临时动作，`live2d_view.py` 绘制眼睛表情和克制的整体姿态。全部复用原透明图与现有 Cubism 模型。

`IdleMotion` 在站立待机时叠加慢眨、双眨、短暂看向别处、翼膜整理、尾尖卷动、后发回落及翼尾组合。安静模式随机间隔 8–15 秒，普通模式 5–10 秒；随机方向、强度、时长并避开最近两次。各部位的微动使用独立的 1.8–4 秒随机目标与平滑插值；短动作按关键帧进入、停留、收回。只选择当前模型实际包含参数的动作。鼠标靠近时让出视线，其他反应、聊天及减少动作模式中清除随机片段；实际触摸表情优先。

`art/bind_q_idle.py` 从带真实透明通道的 PSD 副本绑定 `ParamTail`、`ParamWingL/R`、`ParamIdleAhoge`、`ParamIdleHairL/R`；尾发弯曲固定根部区域；翼膜以翼根旋转，向根部衰减；32 像素网格保持变形连续。受限制作命令：`.venv/Scripts/python.exe art/guarded_editor.py --limit-mb 1800 --minimum-mb 800 --script art/bind_q_idle.py`。导出目录为 `art/idle-model-stage`，可编辑工程为 `art/shuangli-q-v1/shuangli-idle.psd2live`。部署必须将完整模型族、纹理、`neutral-backing.png`、`face-backing.png` 与 `idle-rig.json` 放在一起。中性补缝底图排除会动的部位，避免重影；没有此绑定的模型保留原切边幅度。头身和前发仍需遮挡补绘后再增加独立动作。

| 原因 | 反应 | 节奏 |
| --- | --- | --- |
| 鼠标进入角色附近 | 抬眼注意；快速掠入时短暂惊讶 | 注意冷却 22 秒，惊讶冷却 90 秒 |
| 鼠标在附近停留 | 好奇回应、轻倾身注视 | 停留 4 秒，好奇冷却 45 秒 |
| 鼠标停留至少 3 秒后离开 | 目送后收回视线 | 冷却 35 秒 |
| 鼠标在头顶连续轻移 | 眯眼亲近 | 累积位移，冷却 8 秒 |
| 安静陪伴 | 张望、慢眨眼、双眨眼、满足、羞怯微笑、整理翼尾 | 随机 55–100 秒，避开最近三次动作 |
| 普通陪伴 | 同上 | 随机 28–55 秒 |
| 系统短暂无输入 15–90 秒 | 发呆、轻倾身 | 加入闲置候选，不判断为离开 |
| 主人持续操作至少 45 秒，鼠标离角色较远 | 安静注视 | 初次 75–120 秒，随后 2–3.5 分钟 |
| 连续移动至少 4 秒后停稳 | 放松，随后调整翅膀 | 停稳 2 秒后候选，冷却 20 秒 |
| 落地 | 松口气 | 落地 5 秒后候选，冷却 20 秒 |
| 长时间站立 | 抬手伸展 | 初次 65–90 秒，随后随机 3–5 分钟 |
| 拖起后放稳 | 抬手伸展 | 释放后约 6 秒，等待落地与当前反应结束 |
| 持续陪伴且已站稳 | 坐下歇一会儿 | 初次 30–45 秒，随后随机 4–7 分钟，停留 25–40 秒 |
| 系统无输入 90 秒 | 坐下等待 | 恢复输入后恢复陪伴 |
| 系统无输入 3 分钟 | 困倦、打哈欠或闭眼点头 | 每 100 秒选一次；哈欠可接一次点头 |
| 系统无输入 10 分钟 | 闭眼休息 | 停止主动漫游 |
| 离开至少 2 分钟后恢复输入 | 睁眼迎接 | 冷却 45 秒 |
| 等待坐姿时恢复输入 | 振作抬眼 | 中断系统闲置姿态 |
| 移动到屏幕边缘 | 张望、漫游反向 | 冷却 25 秒 |
| 触摸头、脸、角、翼、尾 | 亲近、害羞、惊讶、好奇 | 连续触摸仍由情绪模块处理 |
| 拖起、下落、着地 | 抓取、睁眼下落、落地缓冲 | 临时动作结束后恢复当前陪伴状态 |

自动动作不弹气泡。聊天、生成回复、拖拽、触摸反应及暂停时暂缓自然动作；睡眠由系统闲置触发。鼠标穿透关闭轻抚识别，仍保留远处眼神与闲置节奏。设置中的“自然互动与闲置小动作”控制自动行为，“减少动作幅度”关闭整体姿态位移。

已接受的自然动作结束后留出 4–7 秒空隙。伸展→舒缓、醒来→满足、惊讶→舒缓、走停放松→调整翅膀、哈欠→点头按原因衔接，后续候选最多三个，通常延后 5–8 秒且 12 秒后过期。聊天、拖拽、下落及暂停清除后续；移动可中断正在播放的自然动作。翼尾调整也进入普通闲置候选，不依赖点击。自然动作使用实际片段时长收回姿态；眨眼间隔随机 3.2–7.5 秒，速度随机 0.22–0.34 秒。

系统闲置时间每秒读取一次 `GetLastInputInfo`，行为观察最多每秒 4 次。不会按“未点击角色”判断主人离开。坐姿、闭眼休息、抬手伸展使用 `assets/poses/shuangli-q` 的独立透明姿态；其余反应复用原图和眼睛绑定。姿态绘制期间跳过 Live2D 逐帧渲染，站立时恢复；切换时更新透明点击区域并淡入淡出。翼尾小动作复用现有独立轴，完整步态需继续补绘、绑定。

原图帧按需加载，缓存常态 16 MB、内存紧张时 4 MB；单张超预算图片允许单独保留。缩放缓存常态 8 MB、紧张时 2 MB。低于 1600 MB 可用内存进入资源收缩，高于 1900 MB 恢复；收缩时离屏目标最多 1 倍像素比。只在进入收缩时清空缩放缓存，避免每隔 3 秒反复解码与缩放。容量只约束这些缓存，不代表整个进程内存。

运动按实际帧间隔积分，重力采用带加速度的位移公式，单次间隔上限 0.25 秒用于异常停顿。移动时窗口更新为 60 Hz，拖动、下落和行走复用渲染帧；开始新的反应时立即更新。静止时按设定帧率检查眼睛参数，目标和插值均稳定时跳过模型计算、绘制及 GPU 回读。内存收缩不降低运动速度或强制降到 20 FPS；睡眠最多 10 Hz。

姿态图片通过 `QImageReader` 读取，解码尺寸最多 640 像素边长；通用帧最多 1024 像素。保留完整原素材，不生成重复的尺寸文件。真实姿态只在站稳时主动触发，聊天、抓取和下落可中断；强制中断会清除旧反应恢复栈。闭眼点头复用休息原画，短暂下沉后恢复坐姿；表情以现有眼睛绑定为主，翼尾复用现有独立轴，保持原图切边的克制幅度。

`build.ps1` 使用 `art/guarded_build.py` 顺序打包，CPU 上限 20%，任务内存最多 600 MB，按可用内存缩小预算，保留 1100 MB 可用内存。余量不足则停止自己的打包任务。先输出到 `build/package-stage`，成功后覆盖程序与依赖文件，保留发行目录的 `data`。构建日志位于 `build/packaging.log`。

依赖未变化时，`.venv/Scripts/python.exe art/guarded_build.py --incremental` 复用 `build/ShuangliCompanion/Analysis-00.toc` 与现有发行运行库，只重编译代码、添加行为模块并更新动作定义和文档。依赖、Python 或模型文件发生变化时用完整构建。

参考：[Desktop Mate](https://store.steampowered.com/app/3301060/Desktop_Mate/)、[VPet 动作与状态组织](https://github.com/LorisYounger/VPet)、本地 `research/ds-local-pet/README.md` 和 `research/dsh-dafeiyu/runtime/animation_model.py`。只借鉴行为组织，没有使用参考角色美术。

绘制由 `Pet.paintEvent` 统一完成，Live2D 只生成缓存图像；姿态切换不隐藏/显示绘制控件。过渡使用预乘透明度的加权相加，复用上一次已显示图像，保证重叠区域不因淡出与淡入叠加而闪暗。同一模型内的表情切换仅插值参数，不淡入原图。原生窗口轮廓是各姿态的固定并集，只在缩放或换包时更新。

模型补缝底图以分层 PSD 的原始 `face` 层覆盖睁眼区域，位置 `(209, 328)`，文件 `assets/live2d/shuangli-q/face-backing.png`；保留此文件与原图配套部署，避免闭眼时露出原图眼睛。明显表情使用约 18% 入场、64% 保持、18% 收回的节奏；满足/轻抚接近全闭眼，羞怯用单眼眨动，眼神保留 85% 幅度，头部不拆层拉扯而使用 3–4 度整体轻倾。

## 梗姿势与脚下小窗

assets/poses/shuangli-q/memes 包含六张参考原图生成的透明完整姿态，源图与提示词在 art/shuangli-memes。统一尺度、脚底对齐，整图绘制。

| 原因 | 反应 |
| --- | --- |
| 鼠标快速进入、在龙角停留、持续注视 | 震惊后仰 |
| 25 秒内连续两次抚摸头顶、情绪高时闲置 | 得意叉腰、小幅雀跃 |
| 在翼尾或龙角来回揉动、连续触碰 | 鼓脸抗议、小幅跺脚 |
| 停留至少 12 秒后离开 | 委屈泪眼 |
| 高速抛掷落稳 | 晕圈圈，随后恢复 |
| 系统无输入达到 45 秒，站稳且未编辑聊天 | 趴下装死，随后振作；冷却 3 分钟 |

悬停出现的聊天窗不阻断自然表情；开始编辑才暂停。各部位都有不依赖点击的停留或抚摸触发。动作菜单和手动睡眠入口已移除。原有眼神、坐下、休息、伸展仍自动触发。

脚下输入框只在鼠标靠近身体、周边或输入框时出现；离开后约 0.25–0.35 秒隐藏。草稿、输入焦点和发送状态不延长显示；仅悬停显示不会取得输入焦点或暂停待机动作。
