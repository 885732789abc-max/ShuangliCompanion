# 桌面 Chat 插件

推荐先让 Agent 按 [启动与连接](连接与启动.md) 完成 Python 环境和程序构建，再由下载者在自己的账户中创建隧道、输入密钥。

连接路径：霜璃桌宠 → 本机认证 TCP → `desktop_mcp.py` → OpenAI Secure MCP Tunnel → ChatGPT 自定义 MCP 插件。回复由当前 Chat 调用 `publish_reply(id,text,done)` 交回桌宠。它不会读取 ChatGPT 的 Cookie 或聊天 DOM；是否调用回传工具由当前 Chat 的插件使用决定。

## 下载者配置

1. 启动桌宠，在设置的聊天入口选择“GPT 桌面端”。
2. 到 [OpenAI Platform 隧道设置](https://platform.openai.com/settings/organization/tunnels) 为自己的组织创建隧道，并关联打算使用的 ChatGPT 工作区。记下自己的 `tunnel_id`，取得隧道运行密钥。账户需要相应的 Tunnels 权限。
3. 从 [openai/tunnel-client 最新发行版](https://github.com/openai/tunnel-client/releases/latest) 下载 Windows 客户端，把 `tunnel-client.exe` 放到项目根目录的 `tools/openai-tunnel/`。这个下载文件只留在本机。
4. 在项目根目录的 PowerShell 运行：

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\connect_chat.ps1 -TunnelId tunnel_自己的编号
   ```

   脚本会在本机隐藏输入运行密钥，也可读取当前终端临时设置的 `CONTROL_PLANE_API_KEY`。终端保持运行；配置保存在 `data/tunnel-profiles`，不会进入 GitHub。
5. 打开 [ChatGPT Plugins](https://chatgpt.com/plugins)，添加自定义 MCP server。Connection 选 **Tunnel**，选择或填写自己的 `tunnel_id`，完成插件创建和安装。
6. 回到希望继续的 Chat，选中刚添加的插件，要求它调用 `open_shuangli`。面板显示已连接后，在桌宠输入条按 Enter。保持这个 Chat 与插件面板可用。

如要改用另一条聊天，在新 Chat 中选中插件并重新调用 `open_shuangli`。本机 Codex 插件配置只服务 Codex，不能代替上面的 ChatGPT 登记。

## 连接状态

`open_shuangli` 建立面板编号；面板能使用 `ui/message` 时才登记 ready。面板轮询领取桌宠消息，领取与确认分开，避免重复发送。`publish_reply` 只接受当前等待编号。心跳断开、发送结果不明或插件不可用时，桌宠会显示对应状态，不会自动重发。未连接时，输入条保留草稿并打开 ChatGPT。

本机 `data/chat-status.json` 只记录连接状态，不保存聊天内容。运行回复只在内存中显示。
